# Media status

The user requests actual GTA VI imagery. That request remains open.

Current local assets are original FansGTA SVG illustrations, not game screenshots. They remain in use to avoid representing an unverified third-party rights assumption as permission. The fictional map is also original and explicitly labelled.

Rockstar's official site and legal page could not be consulted because this cloud environment returned a proxy 403 before reaching the hosts. Therefore no Rockstar screenshot has been downloaded, hotlinked, relicensed or represented as cleared for an advertising-supported portal. Attribution alone does not establish permission. Once access is available, inspect the applicable press/media terms and record the exact source, owner, permitted use and credit for each chosen asset before replacing the original art.

The historical first official GTA VI trailer is referenced by its original YouTube URL and optionally embedded with the privacy-enhanced player. It is neither downloaded nor rehosted. No thumbnail is fetched before the reader chooses to load the player. Actual YouTube playback and the current embedding status could not be tested live; tests cover the consent behaviour with a mocked response.
